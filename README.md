# 📝 To-Do List App

A simple and responsive to-do list web application built using **HTML**, **CSS**, and **JavaScript**. This app provides an interactive user interface with smooth animations and transitions. Designed for ease of use, it helps users efficiently manage their daily tasks.

## 🚀 Features

- Add, edit, and delete tasks
- Mark tasks as completed
- Smooth animations and UI transitions
- Responsive design for all devices
- Built with modern JavaScript frameworks

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
